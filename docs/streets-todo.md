# רחובות בלי נקודה (77)

למלא כל אחד כך:
1. לפתוח את הקישור "חיפוש". אם OSM לא מוצא את הרחוב, לחפש אותו במפה לפי השכונה.
2. ללחוץ קליק ימני על אמצע הרחוב ולבחור "הצג כתובת". הקואורדינטות יופיעו בתיבת החיפוש.
3. להריץ בתוך ה-worktree:

    npx tsx scripts/geocode-streets.ts --point <code> <lat>,<lng>

בסיום: `git add packages/shared/data/streets.json` וקומיט.
