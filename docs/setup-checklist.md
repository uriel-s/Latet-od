# הכנות שלא תלויות בתשובות החבר

## 1. בדיקות היתכנות (חצי שעה, לפני כל השאר)
את הבדיקות האלה כדאי לעשות קודם, כי רק הן יכולות לשנות את התוכנית.

- [ ] **Google Places על כתובות בבית שמש.** פותחים את https://www.google.com/maps ומקלידים כ-10 כתובות אמיתיות,
      כולל משכונות חדשות (רמת בית שמש ג'/ד', השכונות החדשות במערב העיר).
      בודקים שהרחוב **ומספר הבית** מזוהים ושהסיכה במקום הנכון.
      זה רק קירוב. הבדיקה האמיתית היא בדמו של Autocomplete אחרי שיש מפתח (סעיף 2).
- [ ] **Waze מהטלפון של החבר.** שולחים לו את הלינק `https://waze.com/ul?q=רש"י%2010%20בית%20שמש&navigate=yes`
      ובודקים שהוא פותח ניווט. מבררים אם יש לו iPhone או Android.
- [ ] **wa.me עם עברית.** שולחים לעצמך את הלינק
      `https://wa.me/9725XXXXXXXX?text=שלום%2C%20לאישור%20האיסוף%20מחר%3A%20https%3A%2F%2Fexample.com%2Fc%2Fabc`
      ובודקים שההודעה נפתחת מוכנה וקריאה.
